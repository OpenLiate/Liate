## Overview

Layer **`[A]`** (`src/layers/agent/`) defines the agent's identity, reasoning loop, skills, sub-agent orchestration, and version control:
- `harness/agent.ts` — `Agent` / `Harness` / `AgentHarness`
- `loop/react.ts` — `ReActLoop` (Thought → Action → Observation → Final Answer + live SSE streaming)
- `skills/` — `SkillResolver` + `sources/` (`local.ts`, `https.ts`, `skills-sh.ts`, `github.ts`)
- `orchestration/subagent.ts` — `SubAgentRunner` (`A.subAgents`)
- `versioning/` — `AgentVersionControl` (`commit`, `log`, `diff`, `checkout`)

## Sub-Agents Under `A` (`A.subAgents`)

Sub-agents live cleanly under **`A`** and reference models in **`L`** via `modelTag` (never duplicating `L` inside `A`):

```ts
export class Coordinator extends liate {
  L = { default: "sarvam/sarvam-105b", fast: "groq/qwen/qwen3.8-27b" };
  A = {
    name: "Coordinator",
    version: "0.3.0",
    intent: "Delegate research to subagent_researcher and write the final answer.",
    subAgents: [
      { name: "researcher", intent: "Gather verified facts.", modelTag: "fast", maxSteps: 3 },
      { name: "writer", intent: "Summarize clearly.", maxSteps: 2 }
    ]
  };
}
```

Sub-agents run in isolated `:memory:` sessions — either autonomously as `subagent_<name>` tools inside `ReActLoop` or directly via `agent.run(prompt, { subAgent: "researcher" })`.

## Skills (`A.skills` & `skills.sh`)

Resolve, install, and inject `SKILL.md` instructions from local files, HTTPS URLs, GitHub, or the `skills.sh` ecosystem:

```bash
liate skills find react-best-practices
liate skills add vercel-labs/skills/find-skills
liate skills update
```

## AI Agent Version Control (`AgentVersionControl`)

Track immutable SHA-256 snapshots of an agent's `L · I · A · T` spec (never storing `E` secrets):

```ts
const vc = new AgentVersionControl();
const v1 = vc.commit(agent.toModule(), { version: "0.1.0", message: "Initial" });
const diff = vc.diff("Coordinator", "0.1.0", "0.2.0");
const restored = vc.checkout("Coordinator", "0.1.0");
```
