## Overview

Layer **`[L]`** is modularized under `src/layers/llm/` into `providers/`, `transport/`, `normalize.ts`, `client.ts`, `router.ts`, and `model.ts`.

OpenLiate **never hardcodes silent model defaults** — you explicitly declare your model string (or `MultiModelMap`) and Liate discovers live models dynamically from each provider's `/models` endpoint.

---

## Supported Providers (v0.3.0)

### 1. Sarvam AI (Sovereign Indic Primary)
* **Format:** `sarvam/<model>` (e.g. `sarvam/sarvam-105b`, `sarvam/sarvam-prism`)
* **Env:** `SARVAM_API_KEY`
* **Features:** Chat completions, reasoning, tool calling, SSE streaming, System-One decisions.

### 2. Groq (Ultra-Low Latency LPU Inference)
* **Format:** `groq/<model>` (e.g. `groq/qwen/qwen3.8-27b`, `groq/openai/gpt-oss-120b`)
* **Env:** `GROQ_API_KEY` (override endpoint via `GROQ_BASE_URL`)
* **Features:** Chat completions, tool calling, SSE streaming, reasoning.

### 3. Ollama (100% Local & Offline)
* **Format:** `ollama/<model>` (e.g. `ollama/gemma4:e2b`, `ollama/llama3.2:latest`)
* **Endpoint:** `http://localhost:11434/v1` (override via `OLLAMA_BASE_URL` or `OLLAMA_HOST`)
* **Env:** Zero API key required locally (optional `OLLAMA_API_KEY` for proxied instances).
* **Hub Agent:** `liate run ollama-agent "Hello!"`

### 4. OpenRouter (469+ Cloud & Free Models)
* **Format:** `openrouter/<vendor>/<model>` (e.g. `openrouter/nvidia/nemotron-3.5-lightning:free`)
* **Endpoint:** `https://openrouter.ai/api/v1` (override via `OPENROUTER_BASE_URL`)
* **Env:** `OPENROUTER_API_KEY` (automatically sends `HTTP-Referer`, `X-Title`, and `X-OpenRouter-Title` headers).
* **Hub Agent:** `liate run openrouter-agent "Hello!"`

### 5. Neon AI Gateway (65+ Branch-Scoped Models)
* **Format:** `neon/<model>` (plus `typesafeai-jev-1-14-0` System-One decisions)
* **Env:** `NEON_AI_GATEWAY_TOKEN` or `NEON_API_KEY`

### 6. Gnani AI (Sovereign Indic Voice)
* **Format:** `gnani/<model>` (`prisma-v3` STT, `timbre-v3` TTS)
* **Env:** `GNANI_API_KEY`

## Multi-Model Layer `[L]` (`MultiModelMap`)

Declare multiple named models directly inside **`L`** and switch per call using `{ modelTag }`:

```ts
import { liate } from "@openliate/liate";

export class MultiModelAgent extends liate {
  L = {
    default: "sarvam/sarvam-105b",
    fast: "groq/qwen/qwen3.8-27b",
    local: "ollama/gemma4:e2b"
  };
  A = { name: "MultiModelAgent", intent: "Route tasks to the best model tag." };
}

const agent = new MultiModelAgent();
await agent.run("Quick summary", { modelTag: "fast" });
await agent.run("Deep analysis"); // uses L.default
```

## Adding a Provider PR (1 File + 1 Line)

1. Create `src/layers/llm/providers/<provider>.ts` implementing `ProviderDefinition`.
2. Add it to `BUILTIN_PROVIDERS` in `src/layers/llm/providers/registry.ts`.

Resilient HTTP (`transport/fetch.ts`), SSE streaming (`transport/sse.ts`), key lookup, and `LLMRouter.listModels()` work automatically.
