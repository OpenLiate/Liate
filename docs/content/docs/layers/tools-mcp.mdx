## Overview

Layer **`[T]`** (`src/layers/tools/`) resolves four tool types through `ToolRegistry` (`src/layers/tools/registry/resolver.ts`):
1. **Built-in Local Tools (`builtin/`)** — `"builtin:datetime"`, `"builtin:math"`, `"builtin:*"`
2. **Direct API-Based Tools (`api/`)** — `{ type: "api", name, method, url, headers }` (`createApiTool()`)
3. **Inline In-Process MCP v2 (`mcp/inline.ts`)** — `{ type: "mcp-inline", name, tools: [...] }` using `@modelcontextprotocol/server` v2
4. **External MCP v2 Servers (`mcp/stdio.ts`, `mcp/http.ts`, `mcp/server.ts`)** — Stdio (`uvx`, `npx`) & Remote HTTP/SSE with retry/timeout

---

## Example Mixing All 4 Tool Types in `T`

```ts
import { liate } from "@openliate/liate";

export class ToolsAgent extends liate {
  L = "groq/qwen/qwen3.8-27b";
  A = { name: "ToolsAgent", intent: "Use tools to answer accurately." };
  T = [
    "builtin:datetime",
    "builtin:math",
    {
      type: "api",
      name: "github_repo",
      description: "Fetch GitHub repository metadata",
      method: "GET",
      url: "https://api.github.com/repos/{owner}/{repo}",
      headers: { "User-Agent": "Liate-Agent-Runtime" }
    },
    {
      type: "mcp-inline",
      name: "local-mcp",
      tools: [
        {
          name: "format_badge",
          description: "Format a release badge",
          parameters: {
            type: "object",
            properties: { project: { type: "string" }, version: { type: "string" } },
            required: ["project", "version"]
          },
          execute: async (a) => `[${a.project} ${a.version}]`
        }
      ]
    },
    {
      command: "uvx",
      args: ["mcp-server-time"],
      tools: ["get_current_time"]
    }
  ];
}
```
