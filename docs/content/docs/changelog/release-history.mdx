## v0.3.5 (Nov 27, 2026) - Sprint 7: A Class IS an Agent — Durable Workflows, Cron, A2A v1.0, FDE & Physical AI Agents

* **A2A v1.0 Protocol:** Added compliant Agent Card discovery (`/.well-known/agent-card.json`, `/.well-known/agent.json`), JSON-RPC `POST /a2a` server, and `A2AClient` peer orchestration.
* **Durable Execution & HITL Checkpointing:** Added `CheckpointStore` for HITL approval pause/resume (`POST /resume`) and SQLite-backed `DurableRunStore` for crash-safe step replay (`agent.resumeWorkflow(runId)`).
* **Workflows & Cron Scheduling:** Added `WorkflowRunner` (`sequence`, `parallel`, `branch`, `sleep`, retries) and zero-dependency `CronScheduler` (`A.schedule`, `GET /cron`, `POST /workflow/resume`).
* **Typed Structured Outputs, Evals & Telemetry:** Added `StructuredOutputResolver` with 1-step self-repair, `EvalRunner`, and `TelemetryTracer` (`p50`/`p95`/`p99`, TTFT, TTFC).
* **FDE & Physical AI Agents (`21/21` Hub Agents):** Verified live FDE (`cold-chain-agent`), physical device control (`phoneyaan-agent` ADB, `photographer-agent`, `screen-agent`, `system-agent`, `scheduler-agent`), and live Neon Postgres / Sarvam / OpenRouter / Gnani / Ollama agents.
* **Automated Test Suite:** Expanded `bun test` to **56 passing tests (234 assertions across 6 test files)**.

## v0.3.0 (Nov 26, 2026) - Sprint 6: Full L·I·A·T·E Modularization, Multi-Model L, Sub-Agents, Vector RAG & Open Source Governance

* **Layer `[L]` Modularization & Multi-Model Map:** Modularized `src/layers/llm/` into `providers/`, `transport/`, `normalize.ts`, `client.ts`, `router.ts`, and `model.ts`. Added `MultiModelMap` (`L: { default, fast, reason }`) + `modelTag` routing, plus the **Groq** provider.
* **Layer `[I]` Universal Integration, 3 Memory Backends & 2026 Vector RAG:** Modularized `src/layers/integration/` into `memory/adapters/` (Local JSON, SQLite/Turso, PostgreSQL/Neon/Supabase), `knowledge/sources/` (local files, 2026 `pgvector` HNSW cosine `<=>`, Pinecone `2026-07` REST API) + `embeddings.ts`, `context/`, `lib/`, `repo/`, and `connectors/` (`http-api`, `webhook`).
* **Layer `[A]` Sub-Agents, Versioning & Modular Skills:** Modularized `src/layers/agent/` into `harness/`, `loop/`, `skills/sources/`, `orchestration/subagent.ts` (`A.subAgents` with `modelTag` pointers to `L`), and `versioning/` (`AgentVersionControl` SHA-256 snapshots, diffs, and rollbacks with zero `E` secrets).
* **Layer `[T]` & `[E]` Modularization:** Modularized `src/layers/tools/` into `mcp/` (`client`, `stdio`, `http`, `inline` MCP v2, `server`), `builtin/` (`datetime`, `math`), `api/` (`createApiTool`), and `registry/resolver.ts`; and `src/layers/environment/` into `env/loader.ts`, `sandbox/guard.ts`, and `resolver.ts`.
* **Open-Source Governance:** Added `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `.github/PULL_REQUEST_TEMPLATE.md`, and `.github/ISSUE_TEMPLATE/*`.

## v0.2.5 (Nov 25, 2026) - Sprint 5: Global Gateways, Live Streaming, Sandbox Hardening & Automated Tests

* **Dynamic Ollama & OpenRouter Gateways + Zero Hardcoded Defaults:** Added zero-hardcode support for local **Ollama** (`ollama/<model>` via `http://localhost:11434/v1`) and **OpenRouter** (`openrouter/<vendor>/<model>` via `https://openrouter.ai/api/v1` with 469+ live discoverable models and `HTTP-Referer` / `X-OpenRouter-Title` headers). Enforced strict zero silent model defaults across TypeScript and Python.
* **End-to-End SSE Streaming & Python SDK Parity:** Added live `parseSseStream` token & reasoning streaming across `LiateLlmClient`, `ReActLoop`, CLI (`liate run`, `liate chat`), Hono `POST /stream`, and Python SDK (`agent.stream()`).
* **Layer `[E]` Sandbox, Layer `[T]` MCP Retry & Layer `[I]` Remote Session:** Added `assertNetworkAllowed()` and `runWithTimeout()` in `EnvironmentResolver`, bounded HTTP MCP retry/timeout in `MCP`, and `RemoteSessionAdapter` + optional `agentId`/`email` in Layer `[I]`.
* **Automated Test Suite:** Added 16-case `bun test` suite covering `AUM`, `OM`, and all 5 `L · I · A · T · E` layers.
