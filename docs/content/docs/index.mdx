## Welcome to OpenLiate

OpenLiate is the sovereign, open-source Object-Oriented Programming (OOP) framework for autonomous AI agents. Built on the **LIATE mathematical decomposition rule**, it unifies reasoning loops, persistent session memory, and Model Context Protocol (MCP) tool execution into production-ready API microservices.

<Callout type="info" title="Selected for Sarvam AI & Exa AI Startup Programs">
OpenLiate is officially selected for the **Sarvam AI Startup Program 2026** (Sovereign Indic AI infrastructure with Sarvam 105B and Bulbul voice across 22+ languages) and the **Exa.ai Startup Program** (YC S21 neural web search and semantic knowledge retrieval).

## 1. Installation & Distribution

OpenLiate is distributed across multiple language ecosystems and official registries. Choose your preferred package manager or installer:

<Tabs items={["npm", "PyPI (Python)", "1-Click Script", "Local Clone"]}>

<Tab value="npm">

### Node.js & Bun

Install the CLI globally or add the library to your project:

```bash
# Global CLI runner (liate)
npm install -g openliate
# or with bun:
bun add -g openliate

# Project dependency (direct package)
npm install openliate

# Project dependency (org-scoped package)
npm install @openliate/liate

# Run instantly without installation
npx openliate run agent.json "Analyze trends in autonomous systems"
```

Available on PyPI under both package names:

```bash
# Direct core package
pip install liate

pip install openliate
```

Verify your Python installation:

```bash
python -c "import liate; print(liate.__version__)"
```

## 2. Frontier Agent in 5 Lines

An autonomous agent in OpenLiate is composed of five foundational layers: **L** (Model), **I** (Integration & Memory), **A** (Agent Harness Loop), **T** (Tools & MCP), and **E** (Environment & Sandbox).

### Python SDK (`liate` / `openliate`)

```python
from liate import Liate

class FrontierAgent(Liate):
    # [L] Large Models: Sarvam AI 105B Indic reasoning or Exa-powered frontier LLMs
    L = "sarvam/sarvam-105b"

    # [I] Integration: Co-located persistent session state
    I = {"memory": "sessions/agentyaan"}

    # [A] Agent Harness: Autonomous ReAct loop with guardrails
    A = {
        "name": "agentyaan",
        "version": "0.2.0",
        "intent": "Frontier Sovereign AI Agent built on Liate",
        "maxSteps": 5
    }

    # [T] Tools: Model Context Protocol (MCP v2 stdio & remote SSE)
    T = {
        "sarvam_ai": {
            "command": "uvx",
            "args": ["sarvam-mcp"],
            "tools": ["*"]
        }
    }

    # [E] Environment: Enterprise sandbox guardrails & secret injection
    E = {
        "SARVAM_API_KEY": "$SARVAM_API_KEY"
    }

# Execute agent in-process
agent = FrontierAgent()
result = agent.run("Introduce Mission AgentYaan and sovereign AI architectures.")
print(result.response)
```

### TypeScript SDK (`@openliate/liate` / `openliate`)

```typescript
import { liate } from "@openliate/liate";

export class FrontierAgent extends liate {
  L = "sarvam/sarvam-105b";
  I = { memory: "sessions/agentyaan" };
  A = {
    name: "agentyaan",
    version: "0.2.0",
    intent: "Frontier Sovereign AI Agent built on Liate",
    maxSteps: 5,
  };
  T = {
    sarvam_ai: {
      command: "uvx",
      args: ["sarvam-mcp"],
      tools: ["*"],
    },
  };
  E = {
    SARVAM_API_KEY: "$SARVAM_API_KEY",
  };
}

// In-process execution:
const agent = new FrontierAgent();
const response = await agent.run("Execute sovereign reasoning workflow.");
console.log(response.text);

// Convert directly into a standard Web API endpoint:
export const POST = agent.toHandler();
```

## 3. CLI Command Reference

Execute agents locally, launch interactive multi-turn REPL sessions, or boot the HTTP runtime server:

```bash
# Run declarative agent.json with prompt:
liate run agent.json "Summarize sovereign AI roadmap"

# Run a pre-packaged Hub agent by name:
liate run sarvam-agent "Namaste! Introduce yourself."

# Launch interactive terminal chat session:
liate chat sarvam-agent

# List all available prebuilt agents in Hub:
liate hub

# Launch high-performance Hono HTTP API server on port 7071:
liate serve --port 7071
```

OpenLiate is engineered ground-up with 1-to-1 fidelity to this 5-element architecture:

## 5. The LIATE Mathematical Foundation

In calculus, the **LIATE Rule** is the universal mnemonic used to break down complex mathematical integration by parts:

> *"Don't build AI agents. Integrate by parts."*

| Calculus LIATE Rule | OpenLiate LIATE Architecture | Purpose |
| :--- | :--- | :--- |
| **`L`** — **Logarithmic** | **`[L]`** — **Large Models & Knowledge Layer** | Sarvam AI 105B/2B, Exa AI neural search, local Ollama & cloud LLMs |
| **`I`** — **Inverse Trig** | **`[I]`** — **Integration & Memory** | Sessions, Postgres, state & persistent memory |
| **`A`** — **Algebraic** | **`[A]`** — **Agent Harness Layer** | Autonomous ReAct reasoning loop & step guardrails |
| **`T`** — **Trigonometric** | **`[T]`** — **Tools & MCP Layer** | Model Context Protocol v2 (stdio & HTTP servers) |
| **`E`** — **Exponential** | **`[E]`** — **Environment & Sandbox** | Process isolation, deterministic guardrails |
