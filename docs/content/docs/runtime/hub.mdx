## Overview

The **Liate Hub** (`hub/agents/`) is OpenLiate's local registry of **21 production & device agents**. Every hub agent follows the 5-layer `L · I · A · T · E` specification (`agent.json` and/or OOP `class extends liate` in `agent.ts`) and uses real tools, databases, APIs, and hardware — zero simulated mocks.

## Running Hub Agents

```bash
# Run any hub agent by folder directory
cd hub/agents/cold-chain-agent
bun --env-file=../../../.env run ../../../src/cli/index.ts run ./agent.json "Check telemetry for TRK-101"

# Or via liate.load() in TypeScript
import { liate } from "@openliate/liate";
const agent = await liate.load("hub/agents/multi-model-agent");
const result = await agent.run("Hello from Liate!");
```
