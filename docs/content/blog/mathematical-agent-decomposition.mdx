In calculus, **integration by parts** (`∫ u dv = uv - ∫ v du`) breaks an otherwise intractable integral into cleanly manageable components. The **LIATE rule** (Logarithmic, Inverse trig, Algebraic, Trigonometric, Exponential) dictates the exact order of decomposition.

We apply this mathematical philosophy to autonomous artificial intelligence.

## The Five Decomposed Layers

```
Agent = L ∘ I ∘ A ∘ T ∘ E
```

1. **L — Large Models Layer**: Pluggable reasoning backends (Sarvam AI, Ollama, OpenAI, Anthropic).
2. **I — Integration & Memory**: Short-term conversation buffers, long-term episodic vector storage, and structured SQL state.
3. **A — Agent Reasoning Loop**: Explicit ReAct (Thought → Action → Observation) cycle with bounded recursion guards.
4. **T — Tools & MCP**: Native Model Context Protocol (v2) client supporting local stdio processes and remote SSE/HTTP tool servers.
5. **E — Environment & Sandbox**: Isolated process sandboxes, secret masking, and deterministic ephemeral filesystems.

By decomposing agent complexity across these five isolated primitives, teams can test, benchmark, and deploy agents with zero prompt leakage.
