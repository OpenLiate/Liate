We are thrilled to announce **OpenLiate**, the open-source backend layer designed from first principles for autonomous AI agents.

## Why OpenLiate?

Modern AI applications have outgrown simple chat prompts. Production agents require determinism, strict secret isolation, sandboxed execution, and native integrations with external APIs and databases.

In OpenLiate, **Class is an Agent, and Agent is an API**. Every autonomous agent is declared through a sovereign configuration file and executed across a unified runtime.

```json title="agent.json"
{
  "L": "sarvam/sarvam-105b",
  "I": { "memory": "vector/sqlite", "session": "stateful" },
  "A": { "mode": "react", "max_iterations": 15 },
  "T": { "tools": ["mcp/fetch", "mcp/github"] },
  "E": { "SARVAM_API_KEY": "$SARVAM_API_KEY" }
}
```
