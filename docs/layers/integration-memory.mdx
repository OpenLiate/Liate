## Overview

Layer **`[I]`** manages conversation history and agent memory across runs. 

It is implemented in `src/layers/integration/memory.ts` and resolved dynamically by `IntegrationResolver`.

---

## Memory Providers

### 1. In-Memory (`InMemorySession`)
Stores messages in RAM. Ideal for ephemeral tasks, microservices, and unit tests:

```json
{
  "I": {
    "memory": "memory"
  }
}
```

### 2. File-Based Persistence (`FileSessionMemory`)
Persists conversations to a local JSON file under `.liate/sessions/` across server restarts:

```json
{
  "I": {
    "memory": ".liate/sessions/my-agent"
  }
}
```

Each session is identified by an RFC 9562 time-ordered **UUIDv7** string, ensuring strictly monotonic ordering.

### 3. Serverless Postgres Vector Memory (Neon)
Configured via standard `DATABASE_URL` to store session state and vector embeddings with zero vendor lock-in.
